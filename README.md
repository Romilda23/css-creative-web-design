# CSS Creative Web Design

## About the Project
A creative webpage developed using HTML5 and CSS3 to practice different styling techniques, visual effects, shapes, and animations.

## Technologies Used
- HTML5
- CSS3

## Concepts Practiced
- CSS Clip-path – Polygon and Hexagon shapes
- CSS Animations and Keyframes
- Opacity effects
- Box-shadow
- Animated card movements
- Registration form UI design
- Creating moon and stars using div elements

## Features
- Creative moon and star background
- Registration form layout
- Animated information cards
- Custom shapes using CSS
- Visual effects using shadows and opacity

## What I Learned
- Creating custom shapes using CSS
- Applying animations with keyframes
- Understanding CSS visual effects
- Designing webpage layouts using HTML and CSS

## How to Run
1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
